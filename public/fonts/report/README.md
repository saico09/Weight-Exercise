# Fuentes de los informes PDF

Subconjuntos latinos de DM Sans, Barlow Condensed, Manrope, Space Grotesk y Fraunces incluidos en los paquetes `@fontsource` del proyecto. Se descomprimieron sus contenedores WOFF a TrueType con FontTools, sin alterar sus glifos, para incrustarlos en los PDF de jsPDF. El generador incluye solo las fuentes del tema seleccionado.

Cada familia conserva su licencia SIL Open Font License 1.1 en el archivo `LICENSE-*.txt` correspondiente. Las mismas familias se usan en la interfaz de Weight&Exercise. Estas fuentes se sirven localmente con la app; no se descargan desde servicios externos al generar un informe.
